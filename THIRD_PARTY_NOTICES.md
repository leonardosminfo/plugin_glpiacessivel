# Third-party notices

The public `0.2-beta` GitHub package is built with the `marketplace` profile. It excludes offline speech models and the local Piper/ONNX/Vosklet runtime directories while their redistribution evidence is being completed.

The package includes axe-core for local accessibility checks. Its license is distributed with the source at `assets/vendor/axe-core/LICENSE`.

Optional offline voice assets present in a development checkout are not part of the public package. Operators must validate origin, license and hashes before deploying a separate offline bundle. See `docs/voice_assets_inventory.md`.

GLPI, Formcreator and VLibras are separate projects and retain their respective trademarks and licenses.
